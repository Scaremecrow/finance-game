## 这是什么

一款挂机向的文字经营 / 投资模拟游戏。你只有一笔启动资金和无限的时间，
每天都会被扣掉生活费，躺着不动会被吃穷。想活下去就得去挣、去投、去赌一把。

没有终点，也没有存档云同步——破产是唯一的强制出口。

## 玩法特色

| | |
|---|---|
| 💹 **四种资产** | 债券 / 基金 / 股票 / 加密币，价格 = 内在价值线 + 对数均值回归，不会随时间失控膨胀 |
| 📈 **高估低估指示** | 每张资产卡直接画出当前价格偏离合理价多远，一眼看出贵还是便宜 |
| 💼 **挂机式职业** | 4 档岗位随工龄自动升职，工资日结；可以选择加班（多赚，但会累倒） |
| 🏪 **经营生意** | 投入本金换固定日现金流（营收 − 人工），一个人管不了太多店 |
| ⚡ **杠杆交易** | 2~5 倍做多做空，开仓前就能看到爆仓价和每日融资利息 |
| 🎲 **随机出身** | 8 种开局 + 「一穷二白」，每局都能重选，且抽不到乞丐也抽不到富翁 |
| 📋 **抉择事件** | 涨租、裁员、猎头来电话、内幕消息……每个选择都要自己拍板 |
| 🏠 🎟️ 🏆 | 住房升级 / 彩票 / 成就系统 / 无尽模式（摸到 ¥1 亿可开启下一世代） |

## 怎么玩

- **在线玩**：直接打开上面的试玩链接，微信里也能点开。
- **本地玩**：下载 `index.html`，双击用任意浏览器打开即可，不需要装任何东西。

存档保存在浏览器本地（`localStorage`），关掉再打开进度还在。

## 技术

单文件 HTML + 原生 JavaScript + CSS，**没有构建步骤、没有第三方依赖、没有后端**。
全部逻辑（行情模型、经济系统、UI）都写在一个 `index.html` 里，约 234 KB。
